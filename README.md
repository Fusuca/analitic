# Программа анализа валютных курсов методами сглаживания

## Описание проекта

Программа разработана на языке **C# (Windows Forms)** и предназначена для анализа временных рядов валютных курсов с использованием методов сглаживания и прогнозирования.

В качестве исходных данных используются временные ряды курсов валют:

- USD (доллар США);
- EUR (евро);
- RUB (российский рубль).

Программа позволяет визуализировать исходные данные, строить графики результатов обработки и выполнять сравнение различных методов анализа временных рядов.

---

## Реализованные методы

### 1. Метод простого скользящего среднего (Moving Average)

Позволяет сглаживать случайные колебания временного ряда путем усреднения нескольких последних значений.

Формула:

MA = (X1 + X2 + ... + Xn) / n

где:
- Xi — значение ряда;
- n — период сглаживания.

Параметр:
- Период сглаживания.

---

### 2. Метод взвешенного скользящего среднего (Weighted Moving Average)

Учитывает важность последних наблюдений путем назначения им различных весов.

Формула:

WMA = (X1×W1 + X2×W2 + ... + Xn×Wn) / (W1 + W2 + ... + Wn)

где:
- Xi — значение ряда;
- Wi — вес соответствующего значения.

Параметр:
- Период сглаживания.

---

### 3. Метод экспоненциального сглаживания (Exponential Smoothing)

Придает больший вес новым значениям и меньший вес старым данным.

Формула:

S(t) = α × X(t) + (1 − α) × S(t−1)

где:
- X(t) — текущее значение ряда;
- S(t−1) — предыдущее сглаженное значение;
- α — коэффициент сглаживания.

Параметр:
- Коэффициент α (от 0 до 1).

---

### 4. Метод экспоненциального сглаживания с трендовым регулированием (Holt Trend Method)

Учитывает уровень ряда и его тренд.

Формулы:

Уровень:

L(t) = α × X(t) + (1 − α) × (L(t−1) + T(t−1))

Тренд:

T(t) = β × (L(t) − L(t−1)) + (1 − β) × T(t−1)

Прогноз:

F(t+1) = L(t) + T(t)

где:
- L(t) — уровень ряда;
- T(t) — тренд;
- α — коэффициент сглаживания уровня;
- β — коэффициент сглаживания тренда.

Параметры:
- Alpha (α);
- Beta (β).

## Возможности программы

- выбор анализируемой валюты;
- отображение временного ряда;
- построение графиков курса;
- расчет скользящей средней;
- расчет взвешенной скользящей средней;
- расчет экспоненциального сглаживания;
- расчет экспоненциального сглаживания с трендом;
- визуальное сравнение результатов;
- настройка параметров методов.

## Интерфейс программы

Каждый метод реализован в отдельной форме.

Основные элементы интерфейса:

- ComboBox — выбор валюты;
- TextBox — ввод параметров метода;
- Button — запуск расчета;
- Chart — построение графиков;
- TextBox — отображение временного ряда.

## Пример использования

### Скользящая средняя

1. Выбрать валюту USD.
2. Ввести период сглаживания 3.
3. Нажать кнопку «Расчет».
4. На графике появятся:
   - исходный курс;
   - линия скользящей средней.

### Экспоненциальное сглаживание

1. Выбрать валюту EUR.
2. Ввести α = 0.5.
3. Нажать кнопку «Расчет».
4. Будет построена линия сглаженного ряда.
